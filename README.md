# ⚠️ mikubot 已更名为 Shiori —— 本仓库已迁移

> **项目已搬到 → [github.com/iownmmiku/Shiori](https://github.com/iownmmiku/Shiori)**
>
> This repository is an **intentionally empty placeholder**. The project was renamed from *mikubot* to **Shiori** and now lives at <https://github.com/iownmmiku/Shiori>.

## 这是什么

- 本仓库**不含源码、不含程序、没有可下载的安装包**，也不再维护。请不要在这里提 Issue 或 PR。
- 它只是占住旧名字 `iownmmiku/mikubot`，原因是 **Shiori 0.1.6 及更早版本**（当时叫 mikubot）的“版本与更新”功能写死了向这个地址查询新版本。
- 为了让那些旧版本查询时看到的是一条说明，而不是“更新接口不属于 mikubot 仓库”的报错，这里保留了一个只有文字、没有文件的发行页。

## 我该怎么升级？

1. 打开 **[Shiori 发行页](https://github.com/iownmmiku/Shiori/releases/latest)**，下载最新版本。
   - Windows 一键安装：`shiori-<版本>-Windows-Setup.exe`
   - 便携版：`shiori-<版本>-Windows-x64.zip`
   - 源码：`shiori-<版本>-source.zip`
2. 先退出旧版本，并另存完整的数据目录。
3. 直接覆盖安装 / 解压运行。数据目录、密码、记忆和设置会保留，旧数据自动兼容。

**0.2.0 起程序内置的更新地址已改为 `iownmmiku/Shiori`，之后可以在程序内正常检查和切换版本。**

## 常见问题

- **原来的 Issue、PR、提交历史、旧发行版去哪了？** 都在 [Shiori](https://github.com/iownmmiku/Shiori) 里，编号和历史没有丢。
- **旧的下载文件名还是 `mikubot-0.1.6-…` 吗？** 是的，0.1.6 及更早的发行文件保留原名，位于 [Shiori 的发行页](https://github.com/iownmmiku/Shiori/releases)。
- **为什么 0.1.6 里点“更新”不能直接装 0.2.0？** 旧版更新器只接受它自己的包结构（`mikubot/mikubot.exe`），0.2.0 的包使用 `shiori` 命名，所以需要手动覆盖安装一次。
